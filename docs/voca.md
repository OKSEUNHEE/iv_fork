# 쉬운 투자 용어집

| 말 | 쉬운 뜻 |
| --- | --- |
| 주식 | 회사의 작은 주인표예요. |
| 주주 | 주식을 가진 사람이에요. |
| 배당 | 회사가 이익 일부를 주주에게 나누는 돈이에요. |
| 매출 | 물건이나 서비스를 팔아 들어온 돈이에요. |
| 이익 | 번 돈에서 쓴 돈을 뺀 뒤 남은 돈이에요. |
| 자산 | 회사나 사람이 가진 돈·건물·물건 같은 것이에요. |
| 부채 | 나중에 갚아야 하는 빚이에요. |
| 공시 | 회사가 중요한 소식을 정해진 방법으로 알리는 일이에요. |
| ETF | 여러 자산을 담은 펀드를 주식처럼 사고파는 상품이에요. |
| 채권 | 돈을 빌려주고 나중에 돌려받기로 한 약속과 비슷한 상품이에요. |
| 금리 | 돈을 빌리거나 맡길 때 붙는 돈의 비율이에요. |
| 물가 | 물건과 서비스의 평균 가격이에요. |
| 환율 | 나라 사이 돈을 바꾸는 비율이에요. |
| 분산 | 위험을 줄이기 위해 여러 곳에 나누어 담는 일이에요. |
| 리밸런싱 | 달라진 투자 비율을 처음 계획에 맞게 다시 조절하는 일이에요. |
| 변동성 | 가격이 크게 오르내리는 정도예요. |

> 어려운 말이 나오면 외우기보다, ‘이 말이 내 돈과 어떤 관계가 있지?’라고 먼저 생각해 보세요.
